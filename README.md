# ВСВ ССО · Щоденник

Застосунок психологічної підтримки Всеукраїнської спілки ветеранів Сил спеціальних операцій для ветеранів, військових і їхніх родин. iPhone і Android, один код на Expo (React Native).

Це перший прототип. Він працює без сервера й без фахівця: усе зберігається лише на телефоні.

## Що вже є

| Екран | Що робить |
| --- | --- |
| Знайомство | Ім'я або позивний, хто ви (ветеран, військовий, родина), час ранкового нагадування |
| Сьогодні | Привітання за часом доби, ранкова відмітка, м'які сигнали, ліки на сьогодні, вправа на дихання |
| Ранкова відмітка | Скільки спали, якість сну, настрій, тривога, сили (шкали 1–5), нотатка для себе |
| Динаміка | Графіки сну, настрою й тривоги за 14 днів, середні за тиждень, порівняння з попереднім тижнем |
| Ліки | Список призначених ліків, час прийому, відмітки «прийняв» / «пропустив», щоденні нагадування |
| Допомога | Перевірені кризові лінії з дзвінком в один дотик, запис до психологів спілки, вправа на дихання |
| Налаштування | Ім'я, час нагадування, повне видалення даних |

### Сигнали

Застосунок не ставить діагнозів. Він лише помічає тенденцію й пропонує звернутися по допомогу (`src/lib/insights.ts`):

- настрій 1 і тривога 5 сьогодні — одразу показує кризові лінії;
- настрій ≤ 2 три дні поспіль;
- сон менше 5 годин три ночі поспіль;
- тривога ≥ 4 три дні поспіль.

Пороги робочі. Їх мають переглянути психологи спілки.

## Дані й приватність

- База SQLite шифрується SQLCipher. Ключ (256 біт) генерується на телефоні й лежить лише в Keychain / Android Keystore через `expo-secure-store`, без резервних копій.
- Застосунок нічого не надсилає в інтернет.
- Текст сповіщень не містить назв ліків і відповідей: його видно на заблокованому екрані.
- **В Expo Go шифрування немає** (там немає SQLCipher). Застосунок це перевіряє й показує «Тестовий режим». Для справжнього шифрування потрібна власна збірка (див. нижче).

## Запуск

Потрібні Node.js 20+ і телефон з Expo Go або власна збірка.

```bash
npm install
npx expo start          # QR-код для Expo Go: швидко, але без шифрування
```

Встановити на телефон як звичайний застосунок, з шифруванням (EAS, без Xcode й Android Studio; потрібен безкоштовний акаунт на expo.dev):

```bash
npx eas-cli@latest login
npx eas-cli@latest build --profile preview --platform android   # APK для Android
npx eas-cli@latest build --profile preview --platform ios       # iPhone: потрібен Apple Developer
```

Після збірки EAS дає посилання й QR-код: відкрийте його на телефоні й установіть. На iPhone спершу зареєструйте пристрій: `npx eas-cli@latest device:create`.

Перевірки:

```bash
npm test           # логіка дат, привітань і сигналів
npm run typecheck
npx eslint src
```

## Структура

```
src/app/            екрани (Expo Router): (tabs)/ — вкладки, checkin, med, breathing, settings, onboarding
src/components/     ui.tsx — базові елементи, Bars.tsx — графік
src/lib/            db.ts — база й шифрування, insights.ts — сигнали, notifications.ts — нагадування,
                    crisis.ts — кризові лінії, app.tsx — стан застосунку
```

## Що треба вирішити перед публікацією

- `ios.bundleIdentifier` і `android.package` у `app.json` зараз `ua.vsvsso.app` — замініть на домен спілки.
- `extra.bookingUrl` у `app.json` — адреса сторінки запису на сайті, коли сайт запрацює.
- Іконка й заставка — зараз стандартні від Expo.
- Кризові лінії в `src/lib/crisis.ts` перевірено 22.10.2026; перевіряти щокварталу.
